iTickets iOS PWA TEST

1. Upload the CONTENTS of this folder to a separate GitHub Pages folder/repository, e.g. /itickets-ios-test/
2. Open the HTTPS link in Safari on iPhone.
3. Safari Share button -> Add to Home Screen -> Add.
4. Open iTickets from the Home Screen.
5. Wait until status says Ready, enter board number and press Buy ticket.
6. The generated JPG appears below. Use Save / Share to save it to Photos via the iOS share sheet, or Open image.

Important: Photopea is loaded from photopea.com, so the PSD generation engine requires internet access even though the PWA shell can be cached.
This is a separate test build and does not modify the Android app or the existing stable web build.
